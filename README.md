# cis-portfolio-projects

A collection of Python and data projects, with content and insight taken from my professional experience and interests. Focused on healthcare, operations, and the importance of data visualization in information systems.

## Projects

### Customer Feedback Analysis Tool
Analyzes customer reviews by category, rating, recurring keywords, and service priority.

**Highlights**
- Review categorization
- Average rating analysis
- Recurring keyword detection
- High-priority feedback identification
- Interactive filtering

### Appointment Efficiency Tracker
Analyzes appointment and intake workflows to identify scheduling delays, incomplete records, and operational bottlenecks.

**Highlights**
- Arrival and intake timing analysis
- Workflow bottleneck detection
- No-show and completion metrics
- Custom efficiency scoring
- Appointment-level reporting

### Patient Records / Intake Analyzer
Reviews patient intake records for data quality and basic operational reporting.

**Highlights**
- Missing and inconsistent field detection
- Symptom grouping
- Triage-time analysis
- Record validation
- Flagged record review

## Technologies

- Python
- pandas
- Streamlit
- Data validation
- Basic text analysis
- Operational analytics
